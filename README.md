# AURA Live — Voice Chat & Social Entertainment Platform

Rewritten from Android Kotlin/Compose to modern React, TypeScript, and Tailwind CSS.

## Overview
AURA Live is a real-time voice chat rooms and social entertainment web application. It preserves the complete business logic, moderation tools, and interactive stage systems of the original Bisma Voice Chat project.

## Core Features Ported
- **8-Seat Voice Stage**: Interactive audio stage with host seat, VIP Boss seat #8, speaker guest seats, microphone mute/unmute status, animated sound wave equalizers, and seat locking.
- **Official 1 Frame Management**: Authority system featuring all 14 official frames (Super Admin, Admin, Manager, BD Leader, BD, Agency Leader, Agency, Host, Super Coin Reseller, Coin Reseller, CS Leader, CS, Official, Admin Leader) with conflict-prevention guards, duration presets, live avatar previews, and revocation audit logs.
- **Executive Administration**: User role assignments, ban/unban moderation, coin/diamond balance adjustments, link-user host performance contracts, and system broadcast push notifications.
- **Virtual Gifts & Soundboard**: Tiered gift boutique (Rose, Perfume, Crown, Super Sports Car, Dragon Castle, Rocket) with live floating gift announcements, coin deductions, diamond creator credits, and Web Audio API synthesized soundboard sound effects.
- **Lucky Bags**: Interactive red packet coin drop system with countdowns and randomized claiming among room guests.
- **Social Community & Moments**: Photo feed, comments, likes, and direct messaging with real-time feedback.
- **Avatar & Room Mall**: Collectible frames, animated chat bubbles, luxury entrance rides, and themed stage wallpapers.
- **Global Leaderboards**: Real-time Wealth, Charm, and Top Room podium rankings.
- **Wallet & Economy**: In-app coin recharge packages and diamond-to-coin currency exchange.
